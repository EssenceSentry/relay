# Public example provenance

The Agentic Knowledge Platform document in the homepage chat is a fictional,
self-referential example, as confirmed by the project owner. Its generated
confidentiality footer is template text.

The five `tests/fixtures/dossiers/synthetic-*.md` files were authored from
scratch for parser and renderer tests. Their organizations, scenarios, metrics,
and citation labels are invented. Each fixture states that no external client
document exists. They are formatting examples, not retrieval evaluations or
proof of business outcomes.

The three files in `docs/demo-data/` were also authored from scratch. They
support the demonstration runbook using a fictional service-planning project,
including a deliberate ownership gap. The synthetic answer appears only in
the runbook and should not be included in the initial upload.

The sample-rendering script reads only the checked-in synthetic dossiers. It
does not require private source decks or a downloaded dataset. Rendering may
still apply the standard internal-sales footer; that text does not change the
synthetic provenance of these examples.
